# Privacy Policy

_Last updated: 2026-05-02._

LinkStash for Chrome ("the extension") is a thin client for the
[LinkStash WordPress plugin](https://github.com/apermo/linkstash)
self-hosted by the user. It is designed to send data only to the
LinkStash install the user has explicitly configured.

## What the extension stores

The extension stores three values in `chrome.storage.sync`, scoped to
your Chrome profile and synced across the Chrome installs you are
signed in to:

- The URL of your LinkStash WordPress site.
- A bearer token, generated by you in WP-Admin → Tools → LinkStash.
- A "default visibility" preference (private/public).

It also caches the result of the most recent saved/unsaved checks for
the active tab in `chrome.storage.session`, which Chrome wipes on
browser restart.

That is the entire data footprint.

## Where data goes

The extension makes HTTPS requests **only** to the LinkStash host you
configure. Specifically:

- `GET /wp-json/linkstash/v1/check?url=…` — to determine whether the
  current tab is already saved.
- `POST/PATCH/DELETE /wp-json/linkstash/v1/bookmarks/…` — to save,
  update, or remove a bookmark when you ask it to.
- `GET /wp-json/linkstash/v1/tags?q=…` — for tag autocomplete.

Every request includes your bearer token in an `Authorization` header
so your LinkStash install can attribute the call to your user account.

The extension does **not**:

- contact any analytics, telemetry, error-reporting, or advertising
  service;
- contact any third party other than the LinkStash host you configured;
- read or store the content of pages you visit beyond the URL and tab
  title required to save a bookmark you explicitly asked to save;
- transmit your bearer token to any party other than the configured
  LinkStash host.

## Permissions and why they exist

| Permission | Why |
|---|---|
| `storage` | Persist your host, token, and visibility preference. |
| `activeTab` | Read the current tab's URL and title when you click the action so the popup can prefill the save form. |
| `contextMenus` | Add the right-click "Save link to LinkStash" / "Save page to LinkStash" entries. |
| `notifications` | Show success or error toasts after a context-menu save. |
| `optional_host_permissions: https://*/*` | Allow Chrome to grant the extension access to whichever LinkStash host you enter on the options page, **only after you explicitly approve the prompt**. The pattern is broad because every user runs LinkStash on a different self-hosted domain; the extension itself never talks to anything other than the host you configure. |

## Your data, your server

Because LinkStash is self-hosted, all bookmark content lives on the
WordPress install you control. The extension is the transport, not
the destination — uninstalling the extension removes its local state
(the host URL, token, and visibility preference); your bookmarks
remain on your WordPress site.
